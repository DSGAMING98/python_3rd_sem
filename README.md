## Running a program

Open the repository in PyCharm and run the required `.py` file. Programs 4a,
4b, 4c, 4D and 5D use data files stored beside their Python files.

To run Program 5D, install Matplotlib first:

```powershell
py -m pip install -r requirements.txt
py "Unit 5/program_5d.py"
```

Program 5D creates `daily_sales.png` and `product_sales.png` in the Unit 5
folder.

Earlier practice scripts and dated lab drafts are preserved in `legacy/` for
reference. The assessed final programs are the files named `program_*.py`
inside the Unit 1–5 folders.
